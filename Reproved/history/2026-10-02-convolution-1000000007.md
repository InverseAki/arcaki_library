# mod 1,000,000,007 の畳み込み

Fps/convolution_mod1000000007.rs を追加。元のsrc/、各main.rsは変更なし。
同じスコープの StaticModInt<Mod1000000007> を受け取り同じ型のVecを返す。
ACL 0.1.1版・librarycheckerの同梱MI版どちらにも対応。独自NTT本体を内部モジュールに同梱し、外部のconvolution/NTT traitに依存しない。

```rust
type MI = StaticModInt<Mod1000000007>;
let a = vec![MI::new(1), MI::new(2)];
let b = vec![MI::new(3), MI::new(4)];
let c = convolution_mod1000000007(&a, &b); // [3, 10, 8]
```

Fps/convolution.rs の複数多項式積と組み合わせる場合は、同じスコープで `use convolution_mod1000000007 as convolution;` とする。ACLのglob importとも併用可能。既に別のconvolutionを明示import/定義している場合は、それとの重複を避ける。

短い側が60以下なら愚直積、それ以外は167772161・469762049・754974721の3素数でNTTしCRTで復元。結果長は2^24以下に制限。この制限内では正規化した入力の整数畳み込み係数が3素数の積より小さく、一意に復元できる。i64に収まる係数に限定しない。空入力は空を返す。計算量O(N log N)、領域O(N)。
