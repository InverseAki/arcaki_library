# srcへ統合済み

2026-10-04: Reprovedの実装を `../src/` へ統合した。今後の改善は本体の `src/` に直接反映する。
元のファイル名・公開APIを基本として、旧数学補助関数とMintCombination内のconvolution_mergeも保持した。

このディレクトリの実装ファイルは本体を読み込む互換入口。提出用にコピーするときは `src/` の実体を使う。
旧Cargoテストとrun_*のパスは引き続き利用できる。
履歴の `history/` は過去の検証記録であり、当時の配置・未実施事項を記載している。

統合後の利用方法、挙動の変更点、検証コマンドは [../tests/README.md](../tests/README.md) を参照。
